# Mago Infinito

Juego de supervivencia infinito en el navegador. Elige un héroe (mago, arquero elfo, nigromante o enano artillero), combina habilidades, poderes, objetos y un dragón, y sobrevive el mayor tiempo posible.

- Se juega en el navegador, sin instalar nada (un único archivo `index.html`).
- Funciona en ordenador y en móvil (barra inferior con paneles, zoom con pellizco).
- Controles de escritorio: `P` pausa, `F` velocidad, `Q W E R Z X C V B` poderes, rueda del ratón o `+`/`-` para zoom.
- El ranking se guarda localmente en tu navegador.

Estado: beta.
